# 이탈 고객 관리 (미결제 1주·2주 알림 → 포기 → 분배)

## 적용 순서
1. **Supabase** › SQL Editor 에서 `0042_renewal_churn.sql` 전체 실행
2. **워크허브** — 압축 덮어쓰기 → GitHub Desktop Push
3. **실행 PC** — `renewal.py`, `main.py` 덮어쓰기 → `run.bat` 다시 켜기

## 흐름
- 평일 09:05 연장 체크 때 「이탈」(작업 종료 후 연장 정산 없음, 최근 30일) 업체를 쌓음
- 종료 후 **7일 · 14일** 지나도 연장이 없으면 담당자에게 워크허브 알림 (사람별로 한 건에 묶어서, 같은 단계는 한 번만)
- 담당자: 왼쪽 메뉴 「이탈 고객」 › 내 미결제 › 「포기」(이유 입력) → 분배 대기
- 어드민·총괄: 「포기 업체 · 분배」에서 골라 분배 — 사람 지정 또는 자동(맡은 수 적은 영업사원부터, 원래 담당 제외)
  - 「정산 사이트 고객 배정도 같이」 체크 시 새 담당에게 정산 사이트 고객 배정까지 (사업자번호를 아는 건만)
- 새 담당: 「나에게 넘어온 업체」 — 계약하면 평소처럼 정산요청만 올리면 자동 「연장됨」. 안 되면 「나도 포기」 → 종료
- 누가 팔든 같은 업체·상품의 새 정산이 올라오면 자동 「연장됨」
- 검사기 추가: 「이탈 고객 분배」 — 포기 업체가 3일 넘게 분배 안 되면 노란불

# 팀장 워크허브 테스트 (0043)
1. **Supabase** › `0043_ai_managers.sql` 실행
2. **워크허브** 덮어쓰기 → Push
3. **실행 PC** `engine.py` 덮어쓰기 → `run.bat` 재시작
- 팀장 메뉴: AI팀 (테스트) › 지시 · 작업 현황 — **본인이 넣은 지시만** 보임 (다른 팀장·대표 지시는 안 보임)
- 결과 열기 → 「고쳐 달라고 하기」 = 텔레그램 답장과 같음 (회사 사실은 공통, 취향은 본인 기준으로 학습)
- 끝나면 워크허브 알림 「AI 결과 #번호」. 결과는 ai학습 텔레그램 방에도 올라감
- 개인 기준 이름은 워크허브 이름 기준 (텔레그램 이름과 다르면 따로 쌓임)
