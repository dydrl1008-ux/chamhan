# 워크허브 1-D — 계획 캘린더 · 진급/인센티브 기준 · 진급 도달 현황 · 마이페이지

## 적용
1. SQL Editor: `0010_1d_plans_criteria.sql` (예시 기준 3개·구간 10개 자동 삽입, 이미 있으면 건너뜀)
2. `checks/1d_check.sql` → result = expect
3. GitHub Desktop 덮어쓰기 → Commit `1-D` → Push
4. `node scripts/check-all.mjs` (1-D 항목 추가됨)
5. 어드민 › 기준 관리에서 실제 진급 기준·인센티브 구간으로 교체

## 동작 규칙
- 계획: 일일(파랑)/주간(초록)/월(주황). 본인만 등록·완료 처리·삭제, 팀장은 팀원, 총괄은 전원 열람. 기한 지난 계획 미완료로 되돌리면 사유 입력
- 진급 기준·인센티브 구간: 어드민 편집, 전원 열람. 구간은 빈틈/겹침 있으면 저장 거부
- 진급 판정: 이달 마진 ≥ 기준 & 연속 N개월 충족 & (연 누계) & 지각(월)/결근(연)/병가(월) 허용치 이내 & 재직 개월. 실시간 계산
- 인센티브: 팀원 = 본인 월 마진 구간 요율 × 마진 + 신규 마진 가산 + 보너스 / 팀장 = 팀 합계 마진 구간. 마이너스 마진은 0
- 마이페이지: 이달 마진·목표 %, 잔여 연차, 올해 근태, 계획 달성률, 진급 도달 카드, 인센티브 사다리, (직원) 제출된 주간보고의 본인 지시·피드백
