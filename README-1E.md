# 워크허브 1-E — 상품 · 프로모션 · 관리팀 업무 · 영업이익 · 자산/계정 · 보고서 양식

## 적용
1. SQL `0011_1e_admin_forms.sql` → `checks/1e_check.sql`
2. Vercel 환경변수 **ASSET_SECRET** 추가 (16자 이상 임의 문자열, 계정 비밀번호 암호화 키. 분실하면 저장된 비밀번호 복호화 불가 → 비밀번호 관리 툴에도 보관) → Redeploy
3. GitHub Desktop 덮어쓰기 → Commit `1-E` → Push
4. `node scripts/check-all.mjs`

## 동작 규칙
- 상품 안내·프로모션: 어드민 편집, 전원 열람. 프로모션은 메인 상단 배너(종료일 지나면 자동 숨김)
- 관리팀 담당업무 · 영업이익 월별 · 자산/계정: 어드민 전용 (총괄도 못 봄). 비밀번호는 AES-256-GCM 암호화 저장, '보기' 클릭 시 열람 로그 기록·20초 후 자동 가림
- 영업이익: 월 선택 → 영업이익·항목별 금액·비고 입력 → 실수익 자동. "가져오기" = 이달 KPI 마진 합계. 비용 항목 추가 가능
- 보고서 양식: 어드민이 필드(짧은 글/긴 글/숫자/선택/날짜/체크/자동값 4종) 구성 → 팀·역할·개인·관리팀 배정 → 대상자 '보고서' 메뉴에 매일/매주/매월 주기로 노출. 임시저장/제출, 필수 필드 검사. 양식 수정 시 기존 제출물 보존
