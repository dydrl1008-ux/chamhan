## 적용 순서

### 1. 워크허브 DB
1. Supabase › SQL Editor 에서 `0039_ai_team.sql` 전체 실행 (pg_cron 은 이미 켜져 있음 → 일정 2개 자동 등록)
2. 같은 곳에서 실행기 비밀번호 지정 (영문·숫자 20자 이상, 아무 데도 공유하지 말 것)
   ```sql
   alter role ai_worker password '여기에_긴_비밀번호';
   ```
3. Supabase › 상단 **Connect** › **Session pooler** 주소를 복사해 사용자명만 `ai_worker.jeehtcoccvdnuphopgth` 로 바꾼다. 이것이 `.env` 의 `AI_DB_URL`
   - 예: `postgresql://ai_worker.jeehtcoccvdnuphopgth:비밀번호@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres`

### 2. 워크허브 화면 배포
GitHub Desktop 으로 이 파일들 덮어쓰기 → Push → Vercel 자동 배포. 사이드바에 「알림」, 어드민·총괄에게 「AI팀 (테스트)」 묶음이 생긴다. (환경변수 추가 없음)

### 3. 텔레그램 봇
1. 텔레그램에서 **@BotFather** › `/newbot` › 이름 정하기 → 받은 토큰을 `TELEGRAM_BOT_TOKEN` 에
2. `TELEGRAM_ALLOWED_IDS` 는 비워 둔 채 4단계 진행 → 봇에 아무 말이나 보내면 내 ID를 알려줌 → 넣고 재시작

### 4. 실행 PC
1. **Python 3.11 이상** 설치 (설치 화면에서 "Add python.exe to PATH" 체크)
2. **Claude Code** 설치 — PowerShell 에서 `irm https://claude.ai/install.ps1 | iex`
3. 명령 프롬프트에서 `claude` 한 번 실행 → 회사 **Max 계정**으로 로그인 → 종료
   - 시스템 환경변수에 `ANTHROPIC_API_KEY` 가 있으면 지울 것 (있으면 API 요금으로 나감. 실행기는 실행할 때마다 자동으로 빼고 돌림)
4. 저장소의 `ai-worker` 폴더에서 `.env.example` 을 복사해 `.env` 로 이름 바꾸고 값 채우기
5. `selftest.bat` 더블클릭 → DB · 텔레그램 · Claude 실행이 모두 [통과] 인지 확인
6. `run.bat` 더블클릭 → 텔레그램에 「🤖 AI팀 실행기 켜짐」이 오면 성공. 창은 켜 둔 채로 두기 (꺼지면 15초 뒤 자동 재시작)
7. PC 재부팅 후 자동 실행: `Win + R` › `shell:startup` › 열린 폴더에 `run.bat` **바로가기** 넣기
8. 제어판 › 전원 옵션 › **절전 모드 「안 함」** (잠들면 실행기·일정이 멈춤)

## 1단계 완료 확인 (설계서 완료 기준)
1. 텔레그램에 `/check` → 점검 5개 결과가 온다 (정산 동기화는 실제 06:00 기록 기준)
2. 텔레그램에 「참한기획 신규 셀러용 리워드 소개 메일 초안 써줘」 → 접수 → 비서실장 처리 → 감사팀 검증 → `✅ #번호 … [검증] 통과 · …` 가 오면 **지시 → 실행 → 검증 → 보고 왕복 완료**
3. 워크허브 「AI팀 (테스트)」 › 지시 · 작업 현황에서 같은 번호를 눌러 결과·검증 근거가 보이는지
4. 다음 날 08:00 아침 브리핑 도착, 07:30 점검이 「자동 일정 실행」 초록불

## 지켜지는 규칙
- 실행기는 서비스 키 없이 `ai_worker` 역할로만 접속 — AI 테이블과 알림 쓰기만 가능, 정산·매출·근태 테이블은 못 봄 (검사기는 DB 함수가 대신 확인)
- 사실·숫자가 들어간 결과는 감사팀 통과 전에는 「완료」가 아님. 검증이 실패·불가하면 「반려」로 막음
- 동시 실행 `MAX_PARALLEL`(기본 2, 최대 4), 하루 실행 `DAILY_RUN_LIMIT`(기본 60) 넘으면 텔레그램 알림 후 대기
- 텔레그램은 `TELEGRAM_ALLOWED_IDS` 에 있는 사람 지시만 받음. 총괄 추가 = ID 쉼표로 추가 후 재시작
- 고객·대행사에게 나가는 글은 초안까지만 (발송 기능 없음)

## 문제 해결
| 증상 | 확인 |
| --- | --- |
| selftest `DB 연결` 실패 | 사용자명이 `ai_worker.jeehtcoccvdnuphopgth` 인지, 비밀번호 특수문자는 URL 인코딩(`@`→`%40`, `#`→`%23`) |
| 풀러가 역할을 거부 | Supabase › Connect › **Direct connection** 주소에 사용자 `ai_worker` 로 시도 |
| `Claude Code 실행 파일을 찾을 수 없음` | 설치 후 창을 새로 열었는지, `.env` 의 `CLAUDE_BIN` 에 `claude.exe` 전체 경로 |
| selftest `Claude 로그인 방식` 실패 | 실행 PC에서 `claude` 실행 → `/login` → Max 계정 (API 키 로그인이면 요금이 나가므로 막아 둠) |
| Claude 실행 실패 · 로그인 요구 | 실행 PC에서 `claude` 를 직접 열어 Max 계정 로그인 상태 확인 |
| 텔레그램 답이 없음 | `run.bat` 창이 켜져 있는지, `ai-worker/logs/worker.log` 마지막 줄 |
| 「실행기」 빨간불 | 실행 PC 절전·재부팅 여부, `run.bat` 창 |
| 일정이 안 돎 | SQL Editor 에서 `select ai_sync_schedules();` (또는 AI팀 화면 「일정 다시 등록」) |
