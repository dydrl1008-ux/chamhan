# AI팀 2단계 — 영업지원 (대행사 컨택 · 콜 리스트 · 제안서 열람 추적)

## 적용 순서 (3곳)
1. **Supabase** › SQL Editor 에서 `0040_ai_sales.sql` 전체 실행
2. **워크허브** — 압축 덮어쓰기 → GitHub Desktop Push (환경변수 추가 없음)
3. **실행 PC** — `바탕화면\ai-worker` 에 실행기 파일 3개 덮어쓰기 → `run.bat` 창 닫았다 다시 켜기
   (`engine.py`, `agency.py`, `agents\agency.md`)

| --- | --- | --- |

## 대행사 컨택
- 오픈채팅방 › 메뉴 › **대화 내보내기** 로 받은 txt 를 그대로 올리면 됨 (브라우저에서 홍보글만 추려서 보내므로 큰 파일도 가능)
- 실행기가 추출 → **원문에 실제로 있는 연락처만** 남김 (AI가 지어낸 번호·링크는 버림) → 크몽·연락처 없는 곳 제외 → 같은 곳 중복 제거
- 초안 규칙: 인사 → 연락 계기 한 줄 + 소개서 첨부 안내 → 차별점 한 문단(개발사 직거래·단독 지면·단가 공개·테스트 제공) → 회신 요청 → 서명. 매체명·숫자 단정·후불/수수료 문구 없음. 규칙은 `ai-worker\agents\agency.md` 에서 고침
- 발송은 사람: 「복사」 → 카톡 붙여넣기 → 「보냄 표시」. 여러 곳은 승인 후 「승인 목록 CSV」를 카톡발송기에 사용
- 끝나면 텔레그램으로 「🏢 대행사 추출 완료」

## 콜 리스트
- CSV 첫 줄(열 이름)만 맞으면 됨: **업체명**(필수), 스토어URL, 키워드, 업종, 전화, 광고여부(Y/N), 순위, 이전순위, 리뷰수, 개설일. 애드대시보드 수집 결과를 엑셀로 열어 CSV 저장해 올리면 됨
- 같은 업체를 다시 올리면 정보만 갱신, 순위가 바뀌면 이전 순위를 자동 보관 → 「순위 하락」 점수
- 점수(기본값): 광고 집행 중 30 · 순위 하락 25 · 리뷰 100개 이상인데 40위 밖 20 · 개설 6개월 이내 15 · 전화번호 있음 10
- **평일 09:00 자동 배분**: 영업사원(팀장·직원, 관리팀 제외)에게 1인당 30곳씩, 점수 높은 순으로 번갈아 나눔. 받은 사람에게 워크허브 알림
- 결과를 안 남긴 건은 다음 날 다시 배분 대상. 거절·부재는 30일 뒤 다시 대상. 관심 고객은 본인 「팔로업」에 남음

## 제안서 열람 추적
- 콜 리스트 줄마다 「+ 제안서 추적 링크」 → goat-app 등 제안서 주소(https://) 붙여넣기 → `chamhan.vercel.app/p/코드` 링크가 복사됨 → 고객에게 이 링크로 보냄
- 고객이 열면 열람 기록 후 원래 제안서로 이동. **1회·2회·5회 열람 때 담당 영업사원에게 알림**, 그 줄이 노랗게 표시
- 카톡 링크 미리보기 봇은 열람으로 안 셈. 같은 사람이 10분 안에 다시 연 건 1회
