# 워크허브 1-C — 일간 KPI · 영업 마진 · 가망건 · 팀장 주간보고 · 출근 수정요청

## 적용
1. SQL Editor 순서대로: `0005` → `0006` → `0007` → `0008_1c_manager_targets.sql`
2. `checks/1c_check.sql` → 전부 result = expect
3. GitHub Desktop: 덮어쓰기 → Commit `1-C` → Push
4. 어드민 › 월 목표 마진: 이번 달 팀·개인 목표 입력 (달성률 표시용)

## 동작 규칙
- 월 목표: 팀원 개인 목표는 팀장이 주간보고 D 섹션에서 배정·저장 (0008). 팀 목표 = 팀원 개인 목표 합계(자동). 어드민은 월 목표 마진 메뉴에서 개인 목표 조정 가능
- 연차·반차·월차·병가: 팀장 팀승인 → 총괄/어드민 최종승인. 팀승인 전에는 총괄 화면에 버튼 없음(DB도 차단). 지각·무단결근은 총괄 직접. 팀장은 팀승인 취소, 총괄/어드민은 승인·반려 취소(대기로 복귀) 가능 (0007)
- 모든 버튼 동작은 우측 하단 알림창으로 결과 표시
- 일간 KPI: 직원·팀장이 매일 제출(같은 날 재제출 = 수정). 콜/신규/금일 마진/카톡DB/신규 마진/야근/업무 보고/느낀점. 미래 날짜 불가
- 영업 마진: 별도 입력 없음. KPI '금일 마진' 합산. 직원=본인, 팀장=팀, 총괄·어드민=전사. 일/주/월 탭
- 가망건 파이프라인: 팀장만 등록·단계 변경·종료. 총괄·어드민 열람. 직원은 자기 팀 것 열람
- 팀장 주간보고: A 팀 요약(KPI 자동) / B 파이프라인 / C 이슈·체크포인트 / D 공통 지시 + 인원별 지시·피드백 / E KPI 원문. 팀장 작성·제출, 총괄·어드민 열람. 직원은 본문 못 보고 본인 지시사항만 DB 조회 가능(다음 단계에서 마이페이지에 표시)
- 출퇴근: 현재 KST 시각 이전/10분 후 초과 기록 차단(DB). 잘못 기록 → 수정 요청 → 총괄·어드민 승인 시 반영·지각 재판정
- 지각·무단결근: 팀장 팀승인 없이 총괄·어드민 직접 승인
